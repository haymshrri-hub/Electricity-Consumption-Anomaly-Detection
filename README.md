# Electricity Consumption Anomaly Detection

Machine learning project for detecting unusual electricity consumption patterns using **Isolation Forest**.

### Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

### Approach

Data preprocessing → Feature Engineering → Isolation Forest → Anomaly Detection → Visualization

### Features

* Time-based feature engineering
* Unsupervised anomaly detection
* 24-hour rolling baseline analysis
* Anomaly visualization
